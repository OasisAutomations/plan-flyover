# Plan Flyover

Turn a floor plan (PDF or image) into a 3D model: set the scale, trace walls, add doors and windows, then orbit, walk through, or watch an auto flyover.
Runs entirely in the browser; plans and projects are stored only on the device (IndexedDB). No uploads, no analytics.

Vendored: pdf.js 4.10.38 (Apache-2.0), three.js r169 (MIT).
